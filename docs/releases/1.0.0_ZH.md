# LegnaSend 1.0.0

传文件，也分享空间。由 Legna 维护的跨平台文件共享工具。

- 向附近设备发送文件，管理队列、进度与失败重试。
- 将文件夹设为独立工作区，分别控制访问密码、可见性及上传权限。
- 浏览器内预览受支持的图片、音视频、文本和 Markdown，搜索文档正文。
- 选择多个文件下载，或将文件夹按 ZIP 下载。
- 显示网卡、网段与 VPN／代理状态，提供带密钥、权限与限额的集成 API。
- 保留 LocalSend 原始传输协议；续传依双方和保存目标能力，不支持时使用整文件传输。

## 下载说明

Windows 提供 x64 和 ARM64 便携 ZIP，修复后新构建解压运行 `LegnaSend.exe`；最初发布的旧资产仍包含 `localsend_app.exe`，需重新构建并替换后生效。Windows 包未签名。

Linux 提供 x64 完整目录压缩包，解压后运行 `localsend_app`，需要系统 GTK 3 及相应运行依赖。

Android 提供 ARM64 和 x86_64 独立 APK，使用 **Release 编译＋固定 debug 密钥签名**，用于直接安装；不是 Google Play 正式签名包。与既有安装签名不同时不支持直接覆盖，先妥善保留个人文件和设置。

macOS、iOS 由维护者另行签名与提交，本次不附 Apple 安装包。Windows Win32 不在本次支持范围。

每个包的来源提交及 SHA-256 见 `BUILD-MANIFEST.json` 和 `SHA256SUMS.txt`。不同目标分别通过 CI 构建及架构／资源检查；这不替代各平台物理设备验收。
