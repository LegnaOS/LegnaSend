# LegnaSend 1.0.0

Share files. Create spaces. A cross-platform sharing app maintained by Legna.

- Send to nearby devices and manage queues, progress and retries.
- Share named folder workspaces with separate passwords, visibility and upload permissions.
- Preview supported media, text and Markdown in the browser, including document-content search.
- Download selected files or folders as ZIP archives.
- Identify network interfaces, subnets and VPN/proxy indicators; integrate tools through scoped, rate-limited APIs.
- Preserve the original LocalSend transfer protocol. Resume requires compatible peers and destinations; otherwise whole-file transfer remains available.

## Packages

Windows x64 and ARM64 portable ZIPs are unsigned. Extract the complete bundle and run `localsend_app.exe`; its product display name is LegnaSend.

Linux x64 is a complete tar.gz bundle. Extract and run `localsend_app`; the system needs GTK 3 and associated runtime dependencies.

Android ARM64 and x86_64 APKs use **Release compilation with a stable debug signing key** for direct installation, not Google Play production signing. Existing installations signed with another key cannot be replaced directly; preserve personal files and settings before migration.

Apple signing and store submission are handled separately; this release includes no macOS or iOS installer. Win32 is not included.

See `BUILD-MANIFEST.json` and `SHA256SUMS.txt` for each artifact's exact source commit and checksum. Successful CI compilation and architecture/resource checks do not replace physical-device acceptance.
