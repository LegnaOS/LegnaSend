# LegnaSend 1.0.0 — package revision 2

Updated packages from source `3621618f`, built by CI run `36343560140`. The application version remains 1.0.0; the separate `v1.0.0-r2` release preserves the original downloads.

- Restore workspace folder access in place; prefill names and custom paths, and start stopped sharing services.
- Prefer IPv4, collapse alternate addresses, and place Open beside Copy.
- Remember enabled workspace upload permission without repeatedly asking for approval.
- Support album batch selection and desktop media multi-selection.
- Default unfinished transfer caches to one hour while preserving explicit settings, active transfers and saved files.
- Apply the green LegnaSend mark across native icons and browser pages; animate the active receive-page logo with reduced-motion support.
- Select all entries across browser folder pages and clearly identify ZIP cancellation targets.
- Rename the Windows executable and file properties to LegnaSend.

## Packages

- Windows x64 / ARM64: unsigned portable ZIP; extract the complete bundle and run `LegnaSend.exe`.
- Linux x64: extract the complete tar.gz bundle and run `localsend_app`; GTK 3 runtime dependencies are required.
- Android ARM64 / x86_64: Release APKs signed with the existing stable debug key for direct installation, not Google Play submission.

Original LocalSend protocol compatibility is preserved. Apple packages are handled separately and are not included here. Physical-device acceptance and store submission remain separate from CI results.

Exact source commits and checksums are in `BUILD-MANIFEST.json` and `SHA256SUMS.txt`.
