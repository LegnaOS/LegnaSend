# LegnaSend 1.0.0 — 第二次安装包发布

本次安装包对应源码 `3621618f`，来自 CI `36343560140`。应用版本仍为 1.0.0，独立发布标签为 `v1.0.0-r2`，保留最初版本的下载文件。

- 工作区原记录重新授权目录，预填名称与自定义路径，支持启动已停止的共享服务。
- IPv4 优先，折叠其他地址，复制旁增加系统浏览器打开按钮。
- 工作区允许上传后不再反复询问许可。
- 手机相册批量选择，桌面图片与视频多选。
- 中断缓存默认保留一小时，保留显式设置，保护活动传输与已保存文件。
- 原生图标与共享网页统一绿色 LegnaSend 标志，接收页动画尊重减少动态效果设置。
- 网页跨分页全选，明确 ZIP 任务取消对象。
- Windows 可执行文件及属性改为 LegnaSend。

## 下载说明

- Windows x64／ARM64：未签名便携 ZIP，完整解压后运行 `LegnaSend.exe`。
- Linux x64：完整解压 tar.gz 后运行 `localsend_app`，需要系统 GTK 3 运行依赖。
- Android ARM64／x86_64：Release APK，沿用固定 debug 签名用于直接安装，不用于 Google Play 提交。

保留 LocalSend 原始传输协议兼容性。本次不附 Apple 安装包，Apple 签名与分发独立处理。CI 成功不替代物理设备验收或商店审核。

来源提交与校验值见 `BUILD-MANIFEST.json` 和 `SHA256SUMS.txt`。
