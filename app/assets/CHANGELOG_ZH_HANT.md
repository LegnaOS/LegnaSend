## 1.0.0 (2026-09-25)

### 傳送與接收

- 檔案和資料夾可加入傳送佇列，也可拖到裝置直接傳送。失敗檔案可單獨重試，無需重傳已完成檔案。
- 統一傳輸面板顯示傳送、接收進度和速度，各任務可獨立操作；離開頁面不會停止傳輸。
- 相容的裝置與儲存位置支援大檔案中斷續傳。應用程式重新啟動後重用進度需要重新批准接收；不支援的目的地使用整個檔案重試。
- 檔案儲存完成後才顯示成功，不覆寫現有檔案。延遲結果不會干擾新傳輸，也不會重複寫入歷史記錄。

### 接收目錄與暫存檔案

- iOS 可從「檔案」選擇接收目錄，Android 可選擇系統文件目錄，並記住選擇。權限失效時提示重新選擇，不會擅自改存其他位置。
- 在支援的 Android 儲存位置核對中斷儲存，識別已經完整儲存的檔案，避免重新寫入。
- 接收成功後自動清理核驗通過的暫存副本，啟動或快取維護時重試符合條件的清理。使用中的檔案、成品和歸屬不明的殘留保持不變。
- 可查看接收快取、設定保留期和查看清理結果。結束相容的傳輸時可請求接收端清理；待處理請求不會顯示為已刪除。

### 網頁分享與目錄工作區

- 透過瀏覽器分享檔案，或建立命名目錄工作區。各工作區可獨立啟停、設定密碼，與普通裝置傳輸同時使用。
- 瀏覽和搜尋檔案清單，勾選多個項目，下載檔案或保留巢狀路徑、空目錄的資料夾 ZIP。支援的工作區也可接收經批准的上傳，不覆寫現有檔案。
- 儲存到瀏覽器支援且已授權的目錄時，可暫停、繼續和重試下載。還原的任務保持暫停；普通瀏覽器下載仍使用瀏覽器自己的儲存位置。
- 工作區傳輸可在統一任務面板中管理。可選整合 API 提供存取金鑰、權限範圍、請求限制和應用程式內說明。

### 預覽與閱讀

- 分享頁面可預覽支援的圖片、音訊和影片，提供縮放、播放控制及原始檔案下載。
- 閱讀和搜尋文字、Markdown、大型文件及支援的圖表；需要時可選擇文字編碼。
- 重新整理工作區時保留閱讀位置和選擇。檔案變更後可重新載入，不影響其他下載。

### 連線與隱私

- 每個傳送任務可選擇可用的裝置入口及本機網路連線。所選連線失效時明確提示，不會靜默切換；仍受系統 VPN 和防火牆設定限制。
- 查看網路、VPN 和代理資訊，複製實際分享位址，選擇 HTTP 或 HTTPS 傳輸；HTTPS 使用裝置產生的憑證。
- 離線查看隱私政策。關於頁提供 LegnaSend 官網和原始碼入口，移除不再使用的捐贈與購買入口。

### 使用體驗與限制

- 修復 macOS 沙盒啟動時誤報復原記錄儲存失敗。
- iOS 記住待傳送的系統分享檔案和文字，應用程式重新啟動後還原，但不會自動傳送。關閉選擇器後不再卡在忙碌狀態。
- 改善小螢幕、大字體下的傳輸面板，以及鍵盤操作和輔助功能提示。
- 保持與原版 LocalSend 互傳相容。目錄存取、背景執行和復原能力取決於裝置及儲存服務；Android 暫不支援傳送虛擬檔案和長度未知的檔案。
- 網頁目錄儲存需要瀏覽器支援並取得授權。ZIP 下載不支援封存檔續傳；過於複雜的 Markdown 會保留為可閱讀的原始文字。

LegnaSend 基於 LocalSend，保留原授權條款與作者歸屬說明。
