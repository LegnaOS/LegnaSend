# LegnaSend 更新日志

作者：Legna

1.0.0 当前为开发版本，尚未正式发布。

## 1.0.0 (2026-09-25)

### 发送与接收

- 文件和文件夹可加入发送队列，也可拖到设备直接发送。失败文件可单独重试，无需重发已完成文件。
- 统一传输面板显示发送、接收进度和速度，各任务可独立操作；离开页面不会停止传输。
- 兼容的设备与存储位置支持大文件中断续传。应用重启后复用进度需要重新批准接收；不支持的目标使用整文件重试。
- 文件保存完成后才显示成功，不覆盖已有文件。迟到结果不会干扰新传输，也不会重复写入历史记录。

### 接收目录与临时文件

- iOS 可从“文件”选择接收目录，Android 可选择系统文档目录，并记住选择。权限失效时提示重新选择，不会擅自改存其他位置。
- 在支持的 Android 存储位置核对中断保存，识别已经完整保存的文件，避免重新写入。
- 接收成功后自动清理核验通过的临时副本，启动或缓存维护时重试符合条件的清理。使用中的文件、成品和归属不明的残留保持不变。
- 可查看接收缓存、设置保留期和查看清理结果。结束兼容的传输时可请求接收端清理；待处理请求不会显示为已删除。

### 网页共享与目录工作区

- 通过浏览器共享文件，或建立命名目录工作区。各工作区可独立启停、设置密码，与普通设备传输同时使用。
- 浏览和搜索文件列表，勾选多个项目，下载文件或保留嵌套路径、空目录的文件夹 ZIP。支持的工作区也可接收经批准的上传，不覆盖已有文件。
- 保存到浏览器支持且已授权的目录时，可暂停、继续和重试下载。恢复的任务保持暂停；普通浏览器下载仍使用浏览器自己的保存位置。
- 工作区传输可在统一任务面板中管理。可选集成 API 提供访问密钥、权限范围、请求限制和应用内说明。

### 预览与阅读

- 共享页面可预览支持的图片、音频和视频，提供缩放、播放控制及原文件下载。
- 阅读和搜索文本、Markdown、大文档及支持的图表；需要时可选择文本编码。
- 刷新工作区时保留阅读位置和选择。文件变化后可重新载入，不影响其他下载。

### 连接与隐私

- 每个发送任务可选择可用的设备入口及本机网络连接。所选连接失效时明确提示，不静默切换；仍受系统 VPN 和防火墙设置限制。
- 查看网络、VPN 和代理信息，复制实际共享地址，选择 HTTP 或 HTTPS 传输；HTTPS 使用设备生成的证书。
- 离线查看隐私政策。关于页提供 LegnaSend 官网和源码入口，移除不再使用的捐赠与购买入口。

### 使用体验与限制

- 修复 macOS 沙箱启动时误报恢复记录保存失败。
- iOS 记住待发送的系统分享文件和文本，应用重启后恢复，但不会自动发送。关闭选择器后不再卡在忙碌状态。
- 改善小屏幕、大字体下的传输面板，以及键盘操作和辅助功能提示。
- 保持与原版 LocalSend 互传兼容。目录访问、后台运行和恢复能力取决于设备及存储服务；Android 暂不支持发送虚拟文件和长度未知的文件。
- 网页目录保存需要浏览器支持并取得授权。ZIP 下载不支持归档断点恢复；过于复杂的 Markdown 会保留为可阅读的源文本。

LegnaSend 基于 LocalSend，保留原许可证与作者归属说明。
