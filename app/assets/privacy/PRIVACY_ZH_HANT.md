# LegnaSend 隱私權政策

更新日期：2026年9月26日 · 開發者：Legna · 適用版本：LegnaSend 1.0.0

## 檔案傳給你選擇的目標

LegnaSend 與你允許連線的裝置、瀏覽器和程式共用檔案、文字及所選目錄。普通區域網路傳輸不要求註冊帳戶，也不依賴開發者營運的檔案儲存伺服器。目前應用程式未啟用廣告、追蹤或自動分析服務，不會自動將傳輸檔案上傳給開發者。

裝置探索會向可連線的對端提供你設定的裝置名稱、裝置類型／型號、協定資訊、監聽連接埠和由憑證衍生的裝置識別碼。此識別碼用於連線身分核驗，不用於廣告。對端或瀏覽器會取得其存取權限允許的檔案名稱、大小、目錄資訊及檔案內容。請避免在裝置名稱中填寫希望保密的資訊。

## 權限和共用控制

區域網路權限用於探索與傳輸。檔案及目錄權限用於你選擇的來源和儲存位置。照片權限用於選擇媒體或儲存收到的媒體。系統分享擴充功能透過本應用程式的 App Group 向主應用程式交接你選擇的內容。

你決定是否接受傳輸、開啟快速儲存、發佈工作區、允許網頁上傳或啟用整合 API。不在索引顯示的工作區並不自動變成私有：知道可連線連結的人仍可能按存取設定進入。工作區密碼和 API 金鑰控制存取；HTTPS 保護傳輸鏈路，HTTP 不加密傳輸。工作區密碼不加密已儲存的檔案。

網路、VPN、防火牆及路由設定決定誰能存取監聽服務。本地位址不等於只允許可信裝置存取。關閉共用或撤銷授權不會刪除他人已收到的副本。

## 儲存在裝置上的資訊

應用程式會儲存實現功能所需的設定、裝置身分金鑰、收藏裝置、工作區授權、傳輸歷史和還原紀錄。中斷傳輸可能保留應用程式擁有的 .ls 暫存檔案及還原紀錄。快取管理只移除可以安全確認身分的項目；正式檔案、活動傳輸和身分不確定的外部檔案會保留。具體保留時間取決於工作、權限和清理設定。

整合 API 請求紀錄和診斷紀錄儲存在本地，可能包含裝置／檔案名稱、位址、耗時和錯誤詳情。獲授權的 API 用戶端可讀取其金鑰權限允許的管理資訊。私密金鑰和清理憑證不是普通公開工作欄位。主動匯出或回報前，請檢查紀錄內容。

你可透過應用程式提供的入口刪除歷史及受管快取、關閉或銷毀工作區登記、撤銷金鑰，也可在系統中撤銷檔案、照片和區域網路權限。銷毀工作區登記不刪除原始目錄。解除安裝時，系統按自身規則移除應用程式容器；Files、照片、共用儲存、其他裝置或備份中的檔案可能仍保留，需要在相應位置管理。

## 外部服務與連結

開啟專案或支援連結時，由瀏覽器及目標服務按其隱私規則處理。iCloud 或其他檔案提供者可能依照你的設定同步文件。系統備份和診斷由裝置及 Apple 的相關設定單獨控制。

目前發行配置關閉 WebRTC／公共信令功能。區域網路共用不會自動連線上游公共信令服務。以後如啟用開發者營運的信令、中繼、分析或帳戶服務，須在發佈這些變更前更新隱私聲明和本政策。

## 聯絡與政策變更

專案與支援：[LegnaSend GitHub 專案](https://github.com/LegnaOS/LegnaSend)。

你可透過[專案問題回報](https://github.com/LegnaOS/LegnaSend/issues)提出政策問題。問題頁面是公開的，請勿提交私有檔案、憑證或未經去識別化的紀錄。你主動提交的內容由 GitHub 按該服務的規則處理和顯示。

本政策隨應用程式提供。資料收集、接收方或共用行為變更時，將同步更新政策及發行資訊。商店隱私回答須對應實際發行版本，而不是未來計畫或其他建置。
