# LegnaSend 隐私政策

更新日期：2026年9月26日 · 开发者：Legna · 适用版本：LegnaSend 1.0.0

## 文件传给你选择的目标

LegnaSend 与你允许连接的设备、浏览器和程序共享文件、文本及所选目录。普通局域网传输不要求注册账户，也不依赖开发者运营的文件存储服务器。当前应用未启用广告、跟踪或自动分析服务，不会自动将传输文件上传给开发者。

设备发现会向可达的对端提供你设置的设备名称、设备类型／型号、协议信息、监听端口和由证书派生的设备标识。该标识用于连接身份核验，不用于广告。对端或浏览器会取得其访问权限允许的文件名、大小、目录信息及文件内容。请避免在设备名称中填写希望保密的信息。

## 权限和共享控制

本地网络权限用于发现与传输。文件及目录权限用于你选择的来源和保存位置。照片权限用于选择媒体或保存收到的媒体。系统分享扩展通过本应用的 App Group 向主应用交接你选择的内容。

你决定是否接受传输、开启快速保存、发布工作区、允许网页上传或启用集成 API。不在索引展示的工作区并不自动变成私有：知道可达链接的人仍可能按访问设置进入。工作区密码和 API 密钥控制访问；HTTPS 保护传输链路，HTTP 不加密传输。工作区密码不加密已保存的文件。

网络、VPN、防火墙及路由设置决定谁能访问监听服务。本地地址不等于只允许可信设备访问。关闭共享或撤销授权不会删除他人已收到的副本。

## 保存在设备上的信息

应用会保存实现功能所需的设置、设备身份密钥、收藏设备、工作区授权、传输历史和恢复记录。中断传输可能保留应用拥有的 .ls 临时文件及恢复记录。缓存管理只移除可以安全确认身份的条目；正式文件、活动传输和身份不确定的外部文件会保留。具体保留时间取决于任务、权限和清理设置。

集成 API 请求记录和诊断记录保存在本地，可能包含设备／文件名称、地址、耗时和错误详情。获授权的 API 客户端可读取其密钥权限允许的管理信息。私钥和清理凭证不是普通公开任务字段。主动导出或反馈前，请检查记录内容。

你可通过应用提供的入口删除历史及受管缓存、关闭或销毁工作区登记、撤销密钥，也可在系统中撤销文件、照片和本地网络权限。销毁工作区登记不删除原始目录。卸载应用时，系统按自身规则移除应用容器；Files、照片、共享存储、其他设备或备份中的文件可能仍保留，需要在相应位置管理。

## 外部服务与链接

打开项目或支持链接时，由浏览器及目标服务按其隐私规则处理。iCloud 或其他文件提供器可能依照你的设置同步文档。系统备份和诊断由设备及 Apple 的相关设置单独控制。

当前发行配置关闭 WebRTC／公共信令功能。局域网共享不会自动连接上游公共信令服务。以后如启用开发者运营的信令、中继、分析或账户服务，须在发布这些变化前更新隐私声明和本政策。

## 联系与政策变更

项目与支持：[LegnaSend GitHub 项目](https://github.com/LegnaOS/LegnaSend)。

你可通过[项目问题反馈](https://github.com/LegnaOS/LegnaSend/issues)提出政策问题。问题页面是公开的，请勿提交私有文件、凭证或未经脱敏的日志。你主动提交的内容由 GitHub 按该服务的规则处理和展示。

本政策随应用提供。数据收集、接收方或共享行为发生变化时，将同步更新政策及发布信息。商店隐私回答须对应实际发行版本，而不是未来计划或其他构建。
